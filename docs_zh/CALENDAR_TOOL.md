# 在线节假日日历工具

Agent 的 `get_calendar` 工具查询中国大陆民用放假、调休补班、普通工作日和周末。它已加入默认工具集，聊天时可直接询问“今天是否放假”“10 月 10 日需要上班吗”或“今年的放假安排”。无需配置 API Key，也无需数据库迁移。

## 查询方式

| 参数示例 | 返回范围 |
| --- | --- |
| `{}` | `FUND_BUSINESS_TZ` 时区下的今天，默认 Asia/Shanghai |
| `{"start_date":"2026-10-10"}` | 指定一天 |
| `{"start_date":"2026-10-01","end_date":"2026-10-12"}` | 连续日期，包含首尾，最多 31 天，支持跨年 |
| `{"year":2026}` | 全年放假和调休补班记录，不列普通工作日与普通周末 |

日期必须为 `YYYY-MM-DD`；`year` 不能与日期参数混用。可请求 2000～2100 年，但实际可用年份取决于数据源是否已经提供安排。未公布年份返回 `DATA_NOT_AVAILABLE`，不按星期猜测节假日。

输出 `kind` 为 `holiday`、`makeup_workday`、`weekend` 或 `workday`。调休安排优先于星期规则，所以周六补班会同时显示 `is_weekend=true` 和 `is_workday=true`。这里的工作日含义是民用日历，**不能当成证券交易日**；基金申赎、交易所开市需另核对相关公告。

## 数据来源与时效

默认数据源是第三方 [Timor 节假日 API](https://timor.tech/api/holiday/)，按年度查询 `/year/{year}/`。它不是政府官方接口；放假安排最终以国务院等官方通知为准，例如 [2026 年部分节假日安排通知](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。本工具不硬编码年度放假表。

- `refresh=true` 为默认值，每次查询在线获取年度数据；跨年分别查询两个年份，两年都成功才输出结果。
- `refresh=false` 可以直接使用五分钟内的成功缓存，超过五分钟仍会在线刷新。
- 只缓存校验成功的快照，缓存最多保存六小时。网络请求最多两次，仅对传输错误、HTTP 429 和 5xx 使用 Tenacity 指数退避重试；格式错误和缺失年份不即时重试。
- 在线失败时，可以回退到六小时内的成功快照，并在工具结果中设置 `stale=true`、保留原获取时间及明确警告。没有有效快照则返回错误，不生成推测结果。
- 返回 `sources`、`fetched_at_utc` 和 `cache_used`。`fetched_at_utc` 是本系统获取数据的 UTC 时间，不是官方发布日期或上游修改时间；跨年取两个快照中较早的时间。工具包络的 `as_of` 表示查询结束日期。

空年度、日期键与日期不一致、年份不一致、错误布尔值，以及缺少元旦或国庆记录的年度会被拒绝。这是最低有效性检查，不能保证第三方数据没有遗漏其他假期或调休。第三方服务限流或不可用仍可能影响查询；企业使用可切换到兼容接口的自建或有保障的数据源。

## 配置与接入

在对应的后端环境文件中可配置：

```dotenv
FUND_HOLIDAY_API_BASE_URL=https://timor.tech/api/holiday
FUND_HOLIDAY_API_TIMEOUT_SECONDS=8
```

URL 只能由服务端配置，模型不能指定请求地址。数据通过共享公开日历缓存保存，不携带用户凭证或聊天内容。原有运行时交易时段提示已注明只是按星期和时钟估算，遇到节假日问题应调用本工具；日历查询不会自动确认交易所是否开市。

实现分别位于 `app/integrations/holiday_calendar.py`、`app/services/calendar_service.py` 和 `app/agent/tools/get_calendar.py`。默认工具集版本升级为 `v2`，系统提示版本为 `fund-agent-v3`。重启后端进程即可加载工具。

`tests/test_calendar_tool.py` 覆盖日期校验、四类日期、跨年、全年、缓存时效、未公布年份、上游格式校验、HTTP 重试及真实 LangGraph 工具执行流程。自动测试使用模拟数据，不依赖公共接口可用性，也不调用真实 LLM。

2026-10-08 验证：后端全量测试 434 项通过、2 项跳过，Ruff 和 Pyright 通过。另经真实接口核验，2026 年有 39 条特殊日期记录，10 月 10 日正确识别为周六补班，全年工具输出约 1,878 tokens；当日 2027 年返回空数据，工具明确报不可用。这些在线核验结果是当日快照，后续以重新查询为准。
