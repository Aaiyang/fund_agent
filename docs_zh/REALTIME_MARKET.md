# 今日主要指数实时行情工具

工具名 `get_realtime_market`，位于 `app/agent/tools/market`，与原 `get_market_context` 共属市场工具组。当前工具版本 `v9`，系统提示词 `fund-agent-v13`。基金关联板块工具另见 FUND_SECTORS.md。普通与流式 Agent 共用已注册工具，重启后端后可使用，无数据库迁移。

## 数据来源与范围

复用 `tencent_client.fetch_quotes` 的公开腾讯行情批量接口，一次请求全部所选指数；HTTP 请求有超时与 tenacity 有限指数退避。工具调用不经过历史收盘数据库，不使用联网搜索或日线结果冒充盘中快照。

## 参数与结果

- `index_codes` 可省略，默认全部14只；也可传目录中的1–14个代码，重复项去重。输入 schema 和服务层都执行白名单校验，不接受个股、任意 URL 或模型编造代码。
- `refresh=true` 默认在线查询；false 允许复用15秒内完整、有效的成功快照。失败、空结果、缺指数、缺涨跌幅或时效异常不写入新缓存；缓存损坏或不可用不阻塞在线查询。
- 每只返回 price、change、change_pct、prev_close、open、high、low、amount、quote_time、trade_date、freshness、stale。未提供数值保留未知，不填0；非法点位作为缺失指数。
- 涨跌幅单位为百分点：1.2表示+1.2%；指数点位/涨跌点数不是货币价格；amount单位为人民币元。
- quote_time 带上海时区偏移；fetched_at 单独记录 UTC 获取时间，不能把获取时间当作报价时间。缓存命中保持原获取时间。外层 as_of 是最早可核验报价时间，每只报价仍有自己的时间。

时效状态为 same_day、delayed、previous_session、unknown_time、future_time。盘中按星期/时钟估算连续交易时段，落后超过180秒标记可能延迟；午休/收盘后以本段结束时间核验，正常停更不误标延迟。旧日期、无效/缺失/异常未来时间会标记 stale。时钟不证明实际开市，工具不核验交易所休市日历；公开快照不保证交易所级实时性。

用户可以问“今天大盘各指数涨跌怎么样”“查看沪深300、创业板和科创50现在的行情”。Agent 按系统提示词选择本工具，并在旧日、延迟、缺数时说明范围。旧工具仅适合最近日线收盘概览。

## 验证

`tests/test_realtime_market.py` 覆盖时间校验、非法数值、部分数据、单位、缓存/刷新/跨日、失败不回退历史、HTTP批量编码契约、参数白名单、真实图中普通/流式多轮刷新和轮内重复调用限制。数据替身验证逻辑，外部请求可额外验证供应商可用性；不能把一次成功当作长期可用性保证。
