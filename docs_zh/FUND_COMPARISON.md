# 基金对比研究

明确比较两到三只基金时使用 `start_research(intent="fund_comparison", fund_queries=[...])`。名称复用既有顺序解析和人工确认，全部对象确认后才取证。两个别名若指向同一代码，要求补充对象；A/C的不同代码保留。分别分析多只基金仍使用 `fund_research`。

共享研究子图加载 `fund-comparison`，获取概况、经理、披露持仓及一次 `get_fund_comparison_data`。深度模式复用公告和市场证据。公开对比不读取个人组合；明确个人范围时使用已鉴权的持仓快照。报告复用已有Tracing、Markdown表格及单基金卡片，无需改前端或迁移数据库。

## 量化契约

- 工具只接受两到三个六位代码。同代码去重，不足两个不同代码拒绝；不接受身份、金额或用户提供的净值序列。
- 以 `business_today()` 为共同参考日，请求近一年历史。每只读取最多7秒，串行最多三只，低于子图25秒工具期限。
- 复用现有归一化排除无效、越界和同日冲突数据；每只最多处理1000点，来源截断公开说明。
- 全部对象有效日期交集的首尾构成共同窗口。失败对象保留，不静默缩成成功对象之间的比较；共同日期不足两个返回 `unavailable`。
- 净值变化使用共同端点。风险指标要求窗口内干净且相同的日期覆盖、相邻间隔不超过14个自然日、平均每自然日至少0.45个点。这是保守密度启发式，不是交易日历核验。年化波动率另要求120点，沿用252日口径；不足保留null。
- 缩短、过时、截断或质量不足的证据返回 `partial`。每只保留实际覆盖、点数和缺口，不插值、不前向填充。
- 指标基于未复权单位净值，不是含分红或费用的总回报。共同日期不代表类型、币种或目标相同；当前工具没有完整费用、币种证据。不支持货币基金收益评估、同类排名、相关性或完整持仓重合度。

模型只解释代码证据与条件适配，不用各自snapshot指标拼接量化排名。单基金卡片独立获取数据，不代表共同窗口叠加图；披露持仓保留季度与实际覆盖。

## 验证

执行 `python -m pytest -q tests/test_fund_comparison.py tests/test_research_workflow.py tests/test_research_extensions.py tests/test_fund_analysis_skill.py`，以及项目Ruff和Pyright检查。模拟测试覆盖日期对齐、短窗口、过时、冲突、来源失败、超时取消、重复别名、顺序确认、流式输出和个人范围。真实数据源与模型报告质量需另做集成验证和评估。
