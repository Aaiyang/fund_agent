# 基金关联板块与板块涨跌工具

两个工具均注册在 `fund` 分组：`get_fund_sectors`、`get_sector_market`。当前工具版本 `v9`，提示词版本 `fund-agent-v13`。普通和流式 Agent 共用注册表，重启后端后生效，无数据库迁移。

## 用法

用户可以问“查询这只基金关联哪些板块，再看这些板块今天涨跌”，或“半导体板块现在涨跌多少”。不完整基金名称先走 `search_funds`；取得六位代码后调用 `get_fund_sectors`，再使用结果中的真实 `BK` 代码调用 `get_sector_market`。

| 工具 | 参数 | 结果 |
| --- | --- | --- |
| get_fund_sectors | fund_code；limit 默认5，范围1–5 | 基金名称、类型、披露行业和日期、关联板块代码及证据、未匹配行业 |
| get_sector_market | keyword；sector_type=industry/concept/all；limit=1–5；refresh 默认true | 匹配板块、点位、涨跌点数、涨跌幅、报价时间、时效与单项错误 |

## 关联的含义

基金通常跨行业，工具不强行给出唯一板块。基金资料由 `FundService` 从本地基金表或已有资料提供方取得；行业沿用最近披露行业数据，不额外获取股票实时价格或历史净值。

- `disclosed_industry`：披露行业和行情行业目录经空格、大小写及“行业”后缀归一化后精确匹配。权重是该披露行业占基金净值的百分点，日期为披露截止日。
- `fund_name_hint`：基金名称包含目录板块名，仅为待核验的主题线索；无推断权重，不证明跟踪指数或当前实际配置。
- “制造业”“金融业”等宽行业不会被猜测映射成半导体、银行或证券。未匹配部分原样保留；没有证据就返回未知。成长、价值等泛化风格不当成板块。
- 范围仅为中国A股行业/概念板块，境外、债券、货币及其他不适用基金不建立关联。名称匹配不构成完整持仓分类；若需要更细的持仓归因，需另行引入股票行业分类与完整持仓证据。

板块涨跌不能当作基金当日收益，也不能按披露权重推算基金实时净值。

## 数据和故障处理

板块目录、报价取自东方财富公开接口，参照 [AKShare 行业板块实现](https://github.com/akfamily/akshare/blob/main/akshare/stock/stock_board_industry_em.py)及[概念板块实现](https://github.com/akfamily/akshare/blob/main/akshare/stock/stock_board_concept_em.py)。使用固定主机与参数，用户输入不能成为请求地址。网络故障通过 tenacity 有限指数退避并切换同源备用主机；HTTP 超时8秒，并发最多4。

目录按代码稳定分页，最多20页，每页100条，完整获取才缓存24小时；重复页、总量变化或缺页视为失败。行业与概念目录独立降级，通过 `unavailable_catalogs` 明确不完整，不能把获取失败解释为板块不存在。

报价默认在线刷新；`refresh=false` 可复用15秒内完整成功报价。失败、缺涨跌幅、非法点位和过期报价不写入缓存。单个报价失败保留错误，其他成功结果仍可返回。不会用历史收盘冒充实时行情。

整数协议按来源 `f59` 精度换算点位和涨跌点数，涨跌幅按100缩放。`change_pct=-1.11` 表示 **-1.11%**。`quote_time` 来自来源 Unix 时间 `f86`，带上海时区；每条 `fetched_at` 是 UTC 获取时间。外层 `as_of` 是最早可核验报价时间，不会掩盖个别板块滞后。

复用指数报价时效策略：same_day、delayed、previous_session、unknown_time、future_time；按报价日期和星期/时钟进行保守校验。该时钟不证明实际开市，未核验交易所休市日历，公开快照可能延迟。空值保持未知，不能补成0。

`tests/test_sector_tools.py` 覆盖证据分层、多板块、分类不匹配、目录完整性、报价单位与时间、参数边界、故障缓存及真实 Agent 图中的普通/流式串联与多轮刷新。模型替身验证执行路径，不代表实际模型遵循率已完成评测。现有基金详情 `related-sectors` 占位 API 和前端页面不在本次工具改动范围内。
