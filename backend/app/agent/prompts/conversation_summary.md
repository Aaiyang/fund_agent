## 输出格式约束（必须遵守）

摘要只是**背景事实记录**，不是任务清单，也不是给后续对话的行动指令：

- 用中性、事实性的语气描述（"用户曾询问 X，已给出数据"）
- **禁止**出现"需继续完成 / 待办 / 下一步应 / 尚未完成需继续"等祈使或行动性表述
- 未完成的分析写成事实（"用户曾询问 017487 暴跌原因，尚未给出结论"），让后续对话自行判断是否继续
- 不要使用 markdown 标题层级来模仿任务简报的结构
