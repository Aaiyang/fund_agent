# 股票分析

研究对象必须来自本轮明确上市代码，支持sh/sz/bj六位代码、hk五位代码及us大写ticker。裸六位代码可能与基金代码重叠，不猜市场；只有名称或市场不明先询问。报价验证失败不补造公司名称或行情。身份和取数由运行时控制，报告阶段不调用工具。

按“结论与覆盖日期 → 公司和报价现状 → 历史价格表现及风险 → 近期变化候选解释 → 三期限观察方案 → 缺口”组织。PE/PB和市值是最新快照，币种、金额和百分比口径必须说明；负PE或单一PE不证明便宜。复权价格观察回撤不是用户持仓回撤或确定未来风险。

当前工具只有行情、价格历史和公司概况，没有完整财报、公告正文、盈利预测或股票个人账本。不能以基金持仓快照推断用户直接持有该股票。新闻只有候选关联，不输出精确收益归因、目标价或保证收益。

复制服务端 research-chart 的 stock_price 引用，移动端复用 MarketChart 并直接请求现有 /markets 接口，模型不返回OHLC、URL或脚本。图表随查询更新，不能冒充报告时证据。给短期1–3个月、中期3–6个月、长期6个月以上的条件观察与复核，不自动买卖。
