# 基金操作方案

回答用户当前的建仓、加仓或减仓问题，先给判断与成立条件，再展示证据和方案比较。研究子图已准备完整持仓快照、按计划取证和代码情景；最终报告不得再次调用工具。

1. 明确基金代码与份额、账户范围、拟操作方向。已有投入、成本、市值不等于拟投入金额；没有明确金额不猜测，也不阻止定性分析。基金未在账本中可以研究建仓；持仓读取失败表示未知。
2. 结合经理与策略、区间业绩和风险、披露重仓、板块行情及事件解释支持与反对依据。短期涨跌和成本价不能单独证明应买卖，历史价格位置不是估值分位，事件相关不是确定因果。
3. 使用已确认画像和本轮明确约束评估期限、风险偏好与现有组合的适配。基金账本不包含全部资产、现金和负债，不推断用户可用资金。目标持仓跨账户分别保留成本和币种口径，不随意合并份额类别。
4. 对比“保持现状 / 用户拟操作 / 暂缓观察”，每项给出依据、风险、触发与失效条件。操作前后比例仅引用代码情景，分母为已核验基金资产；新增资金或赎回离开的假设、未计费用必须说明。缺少金额、数据不全时不输出精确操作比例。
5. 给短期1–3个月、中期3–6个月、长期6个月以上的复核计划。禁止承诺收益、回本日期、目标价格，禁止凭模型心算推荐精确金额或所谓最优比例。
6. 投资适配与能否申购分开：没有交易开放、限购和费用证据时标记未核验，不宣称能够实际下单。任何分析不构成导入、记录交易或执行买卖授权。

按需复制真实证据中的 fund-chart / fund-holdings / research-chart 引用。research-chart 的 fund_allocation 由代码提供，前端重新读取当前用户账本试算；其数据时间可能晚于报告，不能把新读数当成报告当时证据。数据缺口与被省略范围必须可见。
