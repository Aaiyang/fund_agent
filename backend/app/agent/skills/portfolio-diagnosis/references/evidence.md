# 持仓诊断证据与口径

## 工具范围

| 工具 | 可引用证据 | 限制 |
| --- | --- | --- |
| get_portfolio | 指定或全部账户的市值、成本、盈亏、收益率、持仓记录行数 | 汇总缺失金额按零处理；fund_count不是去重基金数；data_updated_at为获取时间，非全部净值同日 |
| get_positions(limit=50) | 按市值排序的账户/基金行、成本、盈亏、单行weight、nav_date及更新时间 | 最多50行且无翻页参数；position_count为返回行数；截断见warnings；未知字段可能被省略 |
| get_fund_snapshot | 基金类型、公司、经理、规模、净值业务日期和公开业绩/风险 | 无组合类型汇总、精确同类排名或未来表现；公开指标不等于个人收益 |
| get_fund_holdings | 最近披露股票、行业权重、披露期及卡片 | 前十大非全部、非实时；多基金披露期可能不同；没有全组合穿透结果 |
| get_fund_analysis_data | 一年请求窗口与实际覆盖、日点计算的净值变化/回撤/波动及图表引用 | 未复权净值口径，不是含分红总回报、本人回撤或组合风险 |
| get_fund_sectors → get_sector_market | 披露行业或名称线索、真实板块代码与当前报价 | 名称提示不证明实际配置；宽行业不能强行映射细板块；不覆盖境外资产 |
| get_market_events → identify_event_portfolio_links | 有限事件窗口和持仓潜在关联、实际检查及截断范围 | 关联方向unknown；未匹配不等于无影响；事件与持仓不必同覆盖范围 |
| get_fund_managers / get_fund_announcements | 任职段、共管团队、公告/报告索引、标题变更线索 | 不证明经理个人收益；索引不等于已读取全文 |

## 分母、成本与覆盖

- get_positions.weight和profit_loss_rate、get_portfolio.total_profit_loss_rate为比值，0.1表示10%。股票披露weight及行情change_pct为百分点，9.45表示9.45%，不能再乘100。
- 仓位分母来自同账户范围内已登记市值，不能称为家庭总资产占比。截断后的仓位不重新归一化；列表不能反推未显示行没有金额。
- 同基金不同账户成本分别保留，average_cost_nav_derived表示计算所得成本净值。跨账户合计、A/C策略合并和类型/公司集中金额暂无专用计算接口，不用模型心算制造精确指标。
- 汇总与明细并非同一个数据库快照，若存在差异说明可能更新错位，不能为了相等改写金额。缺失金额、净值或旧日数据导致完整性未知；汇总0不证明真实资产为0。
- profit_loss为账本持有盈亏，不能称指定区间时间加权/资金加权收益、全资产已实现收益或组合历史回撤。现金流、分红及费用未覆盖时明确限制。

## 披露重合与诊断边界

- 只比较已经查询的真实股票代码、各自权重和披露期。不能从共同股票数量推断精确重合度、相关性、收益贡献或当前暴露。不同报告期不当成同期穿透结果。
- 基金名、行业标签和相同管理公司仅是集中线索，经理、策略或底层资产的证据强度要单独说明。没有股票披露可能是类型不适用或数据缺失，不代表没有持仓或风险。
- 当前没有组合聚合、收益曲线、相关性、风险贡献及优化计算工具。不输出模型自行计算的Top3合计、HHI、组合波动/回撤、压力损失、目标调仓金额或最优比例，也不按精确风险分数排名。
- 以数据质量、用户明确期限及已确认偏好给条件方案；不知道现金或负债时不作全资产规划。用户纠正仅影响本轮事实判断，画像或持仓修改仍走现有独立确认流程。

## 复用现有移动端卡片

只复制工具返回完整代码块，不创建新协议或执行代码。

- get_fund_analysis_data.chart_code_block使用fund-chart v2，只有schema_version=2、type=fund_performance、六位fund_code。客户端复用详情组件并直接向后端取数据，不发送私人成本或净值序列给模型。查询时数据可能比回答更新，显示实际日期；不把单基金图称为组合图。
- get_fund_holdings.holdings_code_block使用fund-holdings v1，包含公开股票权重、真实披露期和警告。卡片显示的是基金定期披露，不是本人账户的实时股票。
- 重点基金需要时才提供图表；已有本轮有效代码块复用。无可用证据说明无法展示，不补造曲线、组合饼图、排名或技术指标。
