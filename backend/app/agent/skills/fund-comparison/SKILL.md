# 基金对比

研究子图已经确认全部对象并完成有界取证；最终报告不再次搜索、加载技能或调用工具。公开对比无需用户已持仓。不授权交易或修改持仓。

## 分析流程

1. 列明真实名称、代码和份额类别，保留A/C差异；至少两只不同代码。比较目标使用本轮原文，未明确时先做基本差异对比，不假定风险偏好或期限。
2. 核对类型、数据截止日期和披露期。不同类型可比较用途与风险特征，不强行评出唯一优胜者；类型或币种未知时列出缺口。货币基金不得用固定单位净值判断收益或风险。
3. 量化对比只引用get_fund_comparison_data：列共同起止日期、样本数及各基金指标。snapshot的历史指标与各自走势图不替代共同窗口指标；没有共同窗口就仅做定性比较。收益差、风险差不由模型心算。
4. 对比经理任职变化、规模和策略线索；不把基金整体表现归因于现任个人经理。对披露重仓股和行业描述共性与差异，明确季度与覆盖范围；非同期披露不称为同期穿透，前十大不等于完整资产。
5. 输出条件结论：哪些目标下各基金更适配、需要承担什么取舍、哪些新证据会改变判断。不根据短期涨幅直接给买卖结论；费用、复权总回报、同类排名、相关性及完整持仓重合度没有证据就不量化。
6. 明确要求结合本人持仓时，使用已返回账本和已确认画像；缺失期限、风险承受或资金约束时给条件方案，不编造金额或精确配置比例。

## 报告形状

比较结论与范围 → 基本信息并排表 → 同窗口指标表 → 经理/披露持仓差异 → 条件适配与取舍 → 数据缺口和复核条件。

每个指标保留单位和实际日期，未知使用“暂无可靠数据”。市场事件与公告仅在已取得证据时引用，不为填栏目补造。按需复制各基金现有 fund-chart/fund-holdings 引用；客户端会在报告消息上按同一共同窗口自动渲染同期收益对比图，模型不要生成对比序列或新的叠加图协议。

## 完成条件

全部已确认对象都有对比位置；重要结论有证据或明确缺口；量化窗口与口径已说明；不静默删除失败对象，不宣称获得分红复权或费用数据，不强制排序。不把技能加载成功称为比较完成。
