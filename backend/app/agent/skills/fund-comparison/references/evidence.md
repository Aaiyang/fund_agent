# 基金对比证据边界

| 工具 | 用途 | 限制 |
| --- | --- | --- |
| resolve_fund_for_analysis | 顺序确认名称、代码与份额类别 | 单个模糊匹配也须确认，全部确认前不取证 |
| get_fund_snapshot | 类型、公司、规模、经理、成立时间与净值日期 | 自有历史指标不能当同窗口比较指标，没有完整费用或币种证据 |
| get_fund_comparison_data | 共同实际日期窗口、净值变化、观察回撤、年化波动率 | 未复权单位净值；partial/unavailable及gaps须公开，不提供总回报、预测或综合排名 |
| get_fund_managers | 任职和变化线索 | 不是个人经理超额或贡献数据 |
| get_fund_holdings | 披露重仓股与行业特点 | 保留各自披露期，不是实时全持仓，不能量化完整重合度或相关性 |
| get_fund_announcements | 深度模式中的公开变化线索 | 索引/标题不代表已经读取全文 |
| get_portfolio / get_positions | 明确个人适配需求时的真实账本 | 不是全资产画像或交易授权 |

比例0.1代表10%；披露权重通常为百分点，不能混用。共同窗口不是必然完整一年，新基金可能只有短窗口。缺日不插值、不前向填充；风险指标质量不足时为null，不能改用各基金自身回撤补齐。

get_fund_comparison_data.rows[].chart_code_block只含既有fund-chart v2引用，可逐字插入。客户端独立获取各基金数据，日期可能比报告更新；不声称这些卡片采用报告的共同窗口。没有对比叠加图、URL、序列或可执行脚本。
