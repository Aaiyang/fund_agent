# 板块分析

先确认真实板块名称、BK代码和行业/概念类别。模糊词对应多个板块时列出真实候选供用户确认，不默认选第一项。数据来自服务端取证；报告不再次调用工具。

按“关键判断与日期 → 板块现状 → 变化线索 → 已登记基金关联 → 三期限观察方案 → 缺口”组织。报价时间、抓取时间与披露时间分别陈述。单日涨幅不是长期趋势，也不是估值分位。

只有工具实际返回的事件和基金披露能用于关联；名称线索只是待核验，不能声称整个组合已完成穿透。当前个人账本是基金账本，不是股票持仓。没有价格历史、资金流、行业财报与成分股全量资料时，明确无法给K线、主力净流入、行业盈利预测和估值分位。

按需复制 research-chart 的 sector_quote 引用，移动端直接获取板块报价。当前卡片为报价快照，历史走势图模块待真实数据源接入，不用模型数值补画。给短期1–3个月、中期3–6个月和长期6个月以上的条件复核指标，不承诺收益或实际交易。
